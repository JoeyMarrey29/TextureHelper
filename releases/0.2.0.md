# PERPHEADS Texture Helper 0.2.0

First public GPL-3.0 release for Windows x64.

- Browse local PERPHEADS models and assemble Lua-compatible weapon attachments.
- Right-drag rotation and left-click shared-texture selection.
- Color-matched UV layers and 3D highlights.
- PNG/DDS editing, local autosaved drafts, install and uninstall with retained backups.
- Alpha installation choices without changing original draft pixels.
- Jarheads sight-body installation and corrected texture paths, including filenames with spaces.
- Automatic stable-release checks, confirmed signed updates, and a release log beside the logo.
- [Quick usage guide](https://github.com/JoeyMarrey29/TextureHelper/blob/main/HELP.md).

## Installation

Download **PERPHEADS-Texture-Helper-Setup-0.2.0-win-x64.exe**. Existing portable testers should install Setup once to move onto the automatic-update release channel.

Requires your own Garry's Mod / PERPHEADS Workshop content. Setup downloads WebView2 only if it is missing. No game content or personal drafts are included.

Updater signatures verify release integrity; the Windows executable is not Authenticode-signed, so SmartScreen may display a warning.
