# PERPHEADS Texture Helper 0.2.3

added copy to cliboard buttons for easier editing

- **Copy PNG** copies the active original or edited texture as an image at its original dimensions, preserving alpha without UV lines or display-only adjustments.
- **Copy UV overlay** copies the visible colored UV layers on a transparent background, ready to paste into an image editor.
- Clipboard errors are shown explicitly. Transparency support depends on the receiving application.
- **Export DDS** remains available for DDS files.

Update from the version button beside the logo, or download the latest Setup. Local drafts and installed game skins are retained.
