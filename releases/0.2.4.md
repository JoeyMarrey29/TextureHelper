# PERPHEADS Texture Helper 0.2.4

Added copy and import to/from clipboard

- Clearer **Copy PNG to clipboard** and **Copy UV overlay to clipboard** buttons.
- **Import from clipboard** previews copied image pixels on matching parts and saves them to your local draft, with the same dimension checks as file imports.
- One **Export texture** button opens a popup to choose PNG or DDS before selecting a save location.
- Renamed **Save UV overlay** to **Export UV overlay**.
- The model selection cursor is now the normal arrow; right-drag rotation retains the grabbing cursor.

Clipboard transparency depends on the source and receiving editors. Copy image pixels rather than a file path.

Update from the version button beside the logo, or download the latest Setup. Local drafts and installed game skins are retained.
