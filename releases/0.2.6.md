# PERPHEADS Texture Helper 0.2.6

fixed deprectation with attempted agent integration, this caused saved drafts to not show properly

- Restore compatibility with saved drafts containing original images from the retired experimental AI integration. AI connection and generation are not included.
- Export and import complete `.phskin` packages to share editable drafts or installed/uninstalled VMT/VTF backups. Import creates a new local copy without installing or overwriting another draft.
- Refine Custom skins with a compact Import skin control and separate primary and sharing/deletion actions.
- Delete skin now removes the saved copy and matching installed attachment files, including incomplete leftovers. Modified files and textures still used by other materials are preserved; Uninstall keeps a saved copy.
- Normalize installed material texture references so extension-bearing references do not create duplicate texture entries.

Install this update to replace the older installed executable; opening a development build alone does not update the normal shortcut. Export any unsaved texture edits before closing an older app that reports a save error. Existing local drafts and game content are retained.
