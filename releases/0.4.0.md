# Update v0.4.0 - Pipeline Overhaul

- Support independent component textures with automatic UV composition.
- Texture library for custom textures.
- Automatically handle components with shared VMT/VTFs: when components use different source textures, compose a combined texture atlas for installation, publishing and export while preserving the shared material settings.
- Export composed draft textures to the library without duplicate sources.
- Simplify texture controls and scope UV options to the selection.
- Improve draft thumbnail framing and preserve unchanged previews.
- Reduce autosave, library refresh and idle rendering overhead.
- Offer image resizing with a distortion warning on import.
- Quick switching of component textures.

Workshop downloads and imported skin packages automatically add their textures to the library without installing them into Garry's Mod.
