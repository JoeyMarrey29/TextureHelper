# Update v0.4.1 - Skin Swapping and Install Merging

- Allow easier swapping of already installed skins, with side-by-side previews and explicit replacement confirmation.
- Allow supported power-of-two texture sizes to retain their resolution when they match the original aspect ratio, up to 4096 pixels per side. Other sizes still offer a resize confirmation.
- Shared VTF generation uses the highest-resolution source texture, preserving smaller sources through nearest-neighbour scaling.
- Offer a "merge commit"-style install: merge incoming component textures into an installed shared atlas while preserving other UV regions and existing VMT settings. Conflicting UV overlaps block merging.
- Review the merged result before installation and save it as a separate installed skin for export, uninstall and reinstall. Source drafts remain unchanged.
- Show which weapon and attachment models will actually change, compared with currently installed skins or original content. Sharing a VTF alone does not flag an unchanged model.
- Refresh installed status after replacement, so displaced skins no longer appear fully installed.

Installation continues to use the PERPHEADS phcustomtextures method. Automatic conversion of arbitrary image sizes is not included in this update.
