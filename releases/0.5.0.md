# Update v0.5.0 - AI Skin Generation

Added AI Skin generation, Open AI, Github, Custom MCP/OAuth

- Generate cosmetic skins across the open draft using GitHub Copilot, ChatGPT through Codex, the OpenAI Images API, or a custom remote MCP image tool with OAuth or bearer authentication.
- Install the official GitHub Copilot or OpenAI Codex CLI from inside the app through Windows Package Manager, only after confirmation, then sign in with your own account.
- See your connected GitHub username or ChatGPT account and connection status in the redesigned AI dialog.
- Send a UV guide only by default; opt into a current-texture PNG reference with **Send original VTF** and a moderation warning. Original alpha masks remain local in UV-only mode.
- Show provider content-block reasons and categories when available, separately from subscription/quota errors.
- Review every generated texture before applying the complete batch to the local draft. Nothing is installed into the game automatically.
- Preserve material settings, alpha masks, shared textures and independent component edits. Copilot/Codex-generated PNG originals are saved alongside derived textures.

GitHub Copilot requires an eligible plan and uses AI credits. Codex requires subscription access to built-in image generation and uses ChatGPT/Codex limits without API-key fallback. OpenAI Images API usage is billed separately from ChatGPT subscriptions. Custom services have their own account and billing requirements.

Generating weapon skins may trigger the AI provider's content filters. These restrictions come from the provider, not Texture Helper. Paid live generation is not part of automated testing.
