# Update v0.5.1 - AI Workflow Improvements

Added a better workflow for AI integration to help with content moderation

- Continue the remaining textures after any per-texture failure, without retrying failed requests.
- Retain successful previews and explicitly apply them together; failed textures remain unchanged.
- Show a live card and loading bar for every texture, with queued, generating, validating, ready and failed states.
- Keep provider failure reasons visible on each failed card and recognize Copilot's image-generation safety-block response.
- Include eligible casing/ammunition textures using the same reference selection and failure-handling workflow.

UV-only references remain the default. Provider content policies still apply; these workflow improvements do not bypass moderation or guarantee approval.
