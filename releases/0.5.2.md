# Update v0.5.2 - Better Skin Merging

Editable skin installs now copy only the UV regions used by the selected model parts. This lets multiple skins share one VTF without a fully textured source atlas replacing unrelated installed regions.

- Preserve installed pixels outside the selected UV regions, including when the incoming overlay fills the whole atlas.
- Allow installs that previously stopped because other indexed models referenced the same VTF.
- Show affected models before installation; models sharing the selected UV pixels can still change.
- Keep an explicit option to replace the entire atlas.

Conflicting edits between selected component sources still block the merge.
