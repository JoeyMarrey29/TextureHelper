Keep this texture's alpha channel?

        

        
Some models use alpha for shader masks rather than transparency, so their VTF can look blank in texture viewers. Removing alpha makes the installed VTF opaque, but can change reticle transparency or in-game shader effects.

        
Your original draft, preview and PNG/DDS exports will keep their pixels. This choice affects only installation.

        

          
          
          
        

      

    
    
      

        
Replace installed skin?

        
Different custom skin files are already installed at these paths. Continuing will overwrite them, including any components sharing the texture. Saved drafts and library textures are kept, but replaced game files are not automatically backed up.

        

          
Models that will change

          
Compared with currently installed skins, or original content when no skin is installed. Shared VTFs only count when pixels inside the model's UVs or its material settings change.

          

          

        

        
VTF previews show RGB without alpha masks for visibility. Material-only changes show the VMT scripts instead. Installation uses the PERPHEADS phcustomtextures method.
